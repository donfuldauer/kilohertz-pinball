GOAL
Deliver scripts/gate_a2.sh, the runner for PLAN Gate A2 (table soak), modelled on scripts/gate_a1.sh (read it first: record()/PASS|FAIL|REPORT table, jq-or-python3 binary discovery from cargo JSON, exit non-zero on failure). For every table it builds the bundle and soaks it at novice, standard and expert, judges every Gate A2 criterion per table, runs the deferred readiness soaks, and prints a per-criterion verdict. The verdict is also written to a file so a lost final line can be reconstructed (this happened in Gate A1). You IMPLEMENT AND SMOKE-RUN ONLY (about 20 games per skill per table). You must NOT run the full 1,000-game gate (9,000 games); the Orchestrator runs it later.

GATE A2 (PLAN, verbatim): "For each of the three tables, 1,000 autoplay games at each skill level:
1. Zero stuck, escaped or non-finite balls; zero script errors; zero command-queue overflows.
2. 100 % switch coverage; every declared shot made at least once; every rule mode started at least once.
3. Median game length at the middle skill level between 1 and 6 minutes; scores increase with skill level.
4. Deterministic replay of 20 sampled games per table."
Rules are frozen after A2.
