GOAL
  Render the backglass (layered art with lamp-driven masks and flashers) and a score display that is
  either a procedural DMD dot grid or a 16:9 LCD compositor, to PiP regions or dedicated windows.

DELIVERABLES (PLAN 5.3)
  1. Backglass: layered translite art with lamp-matrix masks and flasher overlays.
  2. DMD mode: 128 × 32 or 192 × 64 procedural dot grid with orange, red or RGB dots.
  3. LCD mode: 16:9 layered sprite, vector font and animation compositor.
  4. Routing to PiP regions or dedicated windows.
  5. (4.6 hand-off, D32) The kit has no DMD scene kind: 5.3 owns the scene format and supplies
     placeholder scenes (at least `scene_powerball_mania`, plus attract/score/game-over basics) so
     `display_scenes` commands have content; document the format.

DESIGN NOTES
  * Score formatting (thousands separators, player rows, credit/ball lines) is a pure, GPU-free
    function with unit + property tests.
  * Displays redraw only on change (PLAN §2.2 render thread: backglass and score surfaces redraw only on
    change) — expose a dirty flag / change detection driven by snapshot lamps + scores + scene state.
  * 4.6 review N4/N7: the 8×16 DMD font smears dense glyphs; acceptable placeholder, do not fix here.

VERIFICATION CRITERIA (PLAN 5.3; `gpu-tests`, lavapipe)
  `gpu-tests` goldens for DMD text, score formatting and lamp-mask blending — each backed first by
  analytic assertions (D30): DMD dot pitch/colour at known dot positions for rendered text, lit vs
  unlit dot luminance ratio; lamp-mask blending linear in lamp intensity (0, 0.5, 1) within tolerance
  in the masked region and zero change outside it; LCD layer order and alpha compositing.

VISUAL CHECKLIST
  DMD dots are round, evenly spaced, unlit dots faintly visible; text readable at 128×32 and 192×64;
  the three colour modes look right; backglass lamp inserts light up only inside their masks; flashers
  bloom-free (5.2 owns bloom) but visibly additive; LCD score legible at 16:9.
